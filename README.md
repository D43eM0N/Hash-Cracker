# Hash Cracker
Basic Hash Cracker to Learn How Hash cracking Works.

## Usage
Run the script with your wordlist file:

```Bash
python script.py wordlist.txt
```

#### Enter the target hash and its type when prompted:

```bash
    Hash to Solve: 5d41402abc4b2a76b9719d911017c592
    Hash Type: md5
```
## Features
    - Uses Python standard hashlib (MD5, SHA1, SHA256, etc.)
    - Reads wordlists line by line
    - Simple CLI interface
